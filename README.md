## Описание проекта

Проект представляет собой **веб-приложение для прогнозирования выходной мощности государственной районной электростанции (ГРЭС)** на основе исторических данных и методов машинного обучения.

Приложение предназначено для:

* оперативного управления режимами работы электростанции;
* анализа факторов, влияющих на генерацию электроэнергии;
* построения краткосрочных и среднесрочных прогнозов мощности.

Проект реализован на **Python с использованием Streamlit**.

---

## Цель и задачи проекта

### Цель

Разработка программного модуля для прогнозирования выходной мощности ГРЭС с применением методов машинного обучения.

### Основные задачи

* Анализ предметной области и структуры данных ГРЭС;
* Предобработка и агрегация временных рядов;
* Исследование сезонности и закономерностей целевой переменной;
* Разработка и обучение моделей:

  * **SARIMAX** — статистический подход с учётом сезонности;
  * **CatBoost** — градиентный бустинг;
* Сравнение моделей по качеству прогнозирования;
* Разработка веб-интерфейса на Streamlit для конечного пользователя.

---

## Используемые методы и подходы

### Анализ данных

* Унификация временных рядов (почасовая частота);
* Исследование пропусков и их природы;
* Агрегирование признаков с учётом предметной области;
* Корреляционный анализ (коэффициент Пирсона);
* Многосезонный анализ (год / сезон / день недели).

### Машинное обучение

#### SARIMAX

* Учитывает тренды и сезонность;
* Поддерживает экзогенные регрессоры;
* Высокая интерпретируемость;
* Хорошо работает с временными рядами с выраженной сезонной структурой.

#### CatBoost

* Градиентный бустинг на решающих деревьях;
* Устойчив к шуму и выбросам;
* Моделирует сложные нелинейные зависимости;
* Высокое качество прогнозирования при большом числе признаков.

## Установка и запуск проекта

### 1️⃣ Клонирование репозитория

```bash
git clone <repository-url>
```

### 2️⃣ Создание виртуального окружения

```bash
python -m venv venv
```

Активация окружения:

* Linux / macOS:

```bash
source venv/bin/activate
```

* Windows:

```bash
venv\Scripts\activate
```

### 3️⃣ Установка всех необходимых библиотек

```bash
pip install \
  streamlit \
  pandas \
  numpy \
  matplotlib \
  seaborn \
  scikit-learn \
  statsmodels \
  catboost \
  optuna \
  joblib
```

### 4️⃣ Запуск веб-приложения

```bash
streamlit run app/app.py
```

После запуска приложение будет доступно по адресу:
[http://localhost:8501](http://localhost:8501)
